# psca Homebrew tap

## Icuity

A native macOS training calendar for intervals.icu. Requires macOS 26 or later; supports Apple Silicon and Intel.

```sh
brew install --cask psca/tap/icuity
```

This is an **unsigned public-testing preview**, not Developer ID signed or notarized by Apple. macOS may block first launch. If you trust the app, attempt to open it, then use System Settings > Privacy & Security > Open Anyway if offered. Homebrew does not bypass this check.

[Source and releases](https://github.com/psca/Icuity)

To update: `brew update` then `brew upgrade --cask icuity`.

Maintainers: copy the cask generated by Icuity's `scripts/package-release.sh` only after its matching GitHub release is public. Never change a published release asset without bumping its version.
